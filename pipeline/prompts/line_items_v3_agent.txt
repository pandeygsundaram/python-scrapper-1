INPUT FORMAT

[HEADER]         column header row — use to understand column order, skip it
[ROW pP]         data row — extract line items from these

---

RULES

1. Each integer in the item number range found at or near the start of a [ROW] is a line item.
2. A row may be prefixed with a category label (e.g. "WALLS", "CEILING", "FLOORING", "TRIMS") before the item number — the label is NOT an item, strip it and extract the item number that follows.
3. A single row may contain TWO item numbers merged together (e.g. "55 56 Note AND MOULDINGS Replace - Laminate Floor"). Split these into two separate items.
4. A row with only text and no leading integer is a continuation of the previous item — append its text to the previous item's description.
5. Skip rows that are: column headers, dimension/area measurements (e.g. "Length:", "Walls:", "Floor:"), subtotal rows, or room section headers.
6. Include ALL items regardless of whether they have pricing — even $0 items and pure-note items. The description is always useful.
7. The description is everything after the item number up to where numbers begin (qty, price columns). Do NOT include quantities, prices, or financial values in description.
8. If the same rows appear twice (duplicate pages in input), de-duplicate — extract each item only once.

{line_items_rules}

---

OUTPUT

Return {"items": [...]} where each item has ONLY:
  item_number  : integer
  description  : string  (description text only — no quantities, units, or prices)

Return ONLY valid JSON: {"items": [...]}
