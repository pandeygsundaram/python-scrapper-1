EXTRACTION RULES

FORMAT A rules (apply when [ITEM N] tags are present):
1. Produce EXACTLY one output object per [ITEM N] tag — no more, no less.
2. Use [CONT] rows only to extend the description or fill in values for the current item.
3. Verify numeric values against the RAW BLOCKS section when available.
4. If two [ITEM] tags appear close together, they are SEPARATE items — do not merge them.

FORMAT B rules (apply when only [ROW] tags are present):
1. Each [ROW pP] line is a candidate item row.
2. A row with a leading integer matching the item number range is a new item.
3. A row with only one non-empty non-numeric cell is a continuation — append to previous item's description.
4. Skip rows that exactly match the column schema (repeated headers).
5. Skip completely empty rows.

Numeric normalization (all formats):
- Strip "$" and "," from numbers → return as float (e.g. "$1,234.56" → 1234.56)
- Return null for missing or non-numeric values
